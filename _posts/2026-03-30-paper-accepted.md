🚀 **Great news!**

Our paper titled  
**“A Differential Memory Attention Mamba for Spatial-Spectral Representation Learning toward Hyperspectral Image Classification”**  
has been officially **accepted in IEEE Access**.

This work introduces a **novel memory-enhanced attention mechanism** designed to improve spatial–spectral representation learning for hyperspectral image classification.

### 🔍 Key Highlights
- Proposes a **Differential Memory Attention Mamba** framework  
- Enhances **long-range dependency modeling**  
- Improves performance on **hyperspectral datasets**  
- Efficient and scalable for real-world applications
